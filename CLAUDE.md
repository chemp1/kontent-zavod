# kontent-zavod - инструменты контент-завода вокруг одного автора

Открытый репозиторий с инструментами и шаблонами: как из текстового файла о человеке
вырастить конвейер текстов в его голосе. Автора в репо нет: в `voice/` лежит вымышленный
пример, чтобы всё запускалось из коробки. Замените его на себя.

## Раскладка

| Папка | Что там |
|---|---|
| `voice/` | Данные автора: канон голоса, регистры площадок, корпус постов, пороги линтера. Сейчас - вымышленный автор; `voice/_templates/` - пустые скелеты |
| `.claude/skills/write-as-author/` | Скилл-автор: пишет и правит тексты голосом из `voice/` |
| `.claude/skills/corrector/` | Скилл-корректор: `lint.py` (линтер голоса), `calibrate.py` (пороги по корпусу), `test_lint.py` |
| `content/` | Данные студии: идеи, план, тренды, память, отчёты. Формат - `content/README.md` |
| `studio/` | Веб-интерфейс к `content/` и `voice/` (Next.js). Ничего не публикует |
| `tools/` | Сборщики входа: тренды из фидов, идеи из своих звонков, замер площадок, корпус Threads |
| `docs/` | Метод, границы, грабли |
| `export/` | Скрипты, которыми этот репо собирается из приватной мастерской |

## Как здесь работают

- Скиллы читают данные из `voice/`, не из самих себя. Личное - в `voice/`, метод - в скиллах.
- Правило без замера - не правило: пороги линтера не правятся руками, их считает
  `calibrate.py` по `voice/corpus/`. Поменялся корпус - пересчитали.
- Робот не пишет постов. Сборщики приносят карточку с углами; текст пишет автор (или скилл
  по его просьбе), публикует человек.
- Память (`content/memory/`) пополняется только с подтверждения.
- Стек: Python 3.12 stdlib для инструментов, Node для студии. Зависимости - в venv внутри
  папки инструмента, не глобально.

## Границы

- Ничего не публикуем и никуда не отправляем: студия и скиллы отдают текст, кнопку жмёт человек.
- Не читаем и не выводим секреты; ключи - из окружения по имени.
- Чужие данные (скрейп площадок, чужие посты) в git не кладём: `**/data/` в `.gitignore`.
- Перед коммитом - `export/check.py --staged` (хук в `.githooks/`).

## Проверка

`./verify.sh` - линтер на сэмплах, калибровка сходится с `voice/thresholds.json`, тесты,
сборщики в `--dry-run`, стоп-лист.
