# kontent-zavod

**[English](README.en.md)**

Инструменты контент-завода вокруг одного автора: как из текстового файла о человеке
вырастить конвейер текстов в его голосе, и не превратить его в конвейер слопа.

Автора здесь нет. В `voice/` лежит вымышленный человек с корпусом постов, чтобы всё
запускалось из коробки. Замените его на себя.

## Что внутри

- **Линтер голоса.** `lint.py` сравнивает черновик не с «хорошим текстом», а с тем, как
  пишет конкретный автор: тире, скобки, хеджи, первое лицо, ритм, длина. Пороги не
  придумываются, их считает `calibrate.py` по корпусу постов.
- **Два скилла для Claude Code.** Автор пишет и правит голосом из `voice/`, корректор
  вычитывает и снимает нейросетевой налёт. Скиллы содержат метод, всё про автора - в данных.
- **Студия.** Веб-интерфейс к папке с текстами: идеи, контент-план, тренды, память,
  отчёты, карта скилла. Файлы - источник правды, git - история. Ничего не публикует.
- **Сборщики входа.** Тренды из фидов с углами под площадки, идеи из своих звонков,
  замеры площадок.
- **Метод и грабли.** `docs/` - зачем это всё, какие границы держат, на что уже наступили.

## Быстрый старт

```bash
git clone https://github.com/chemp1/kontent-zavod.git && cd kontent-zavod

# линтер на двух черновиках вымышленного автора: живой и «написанный нейросетью вообще»
python3 .claude/skills/corrector/scripts/lint.py voice/corpus/samples/draft-ok.md
python3 .claude/skills/corrector/scripts/lint.py voice/corpus/samples/draft-slop.md

# пороги по корпусу, с таблицей обоснований
python3 .claude/skills/corrector/scripts/calibrate.py voice/corpus/channel.json --report

# всё сразу
./verify.sh

# студия
cd studio && npm install && npm run init && npm run dev   # http://127.0.0.1:5180
```

Скиллы работают сразу после клонирования, если открыть папку в Claude Code:
`/write-as-author` и `/corrector`.

## Как завести своего автора

1. Соберите корпус своих постов в `voice/corpus/channel.json`: список
   `{"date", "views", "text"}`. Достаточно 30 постов, лучше 100.
2. `python3 .claude/skills/corrector/scripts/calibrate.py voice/corpus/channel.json --out voice/thresholds.json --report`.
   Таблицу из отчёта вставьте в `voice/fingerprint.md`.
3. Заполните `voice/i_am_just_a_text_file.md` по шаблону из `voice/_templates/`.
   Это главный файл: не стиль, а описание человека, из которого стиль следует.
4. `voice/author.json` - имя, ник, площадки. `voice/registers/` - что каждая площадка
   меняет поверх канона; регистры vc, Хабра, Дзена, TenChat, DTF уже стоят на замерах.
5. Прогоните `./verify.sh`.

## Принципы

- **Голос - это файл, а не промпт.** Методология «I am just a text file».
- **Правило без замера - не правило.** Пороги линтера и регистры площадок стоят на
  посчитанных корпусах, а не на представлениях о хорошем тексте.
- **Инструмент калибруется по автору, а не по идеалу.** Если линтер ругает живой текст
  автора, неверен порог.
- **Робот не пишет постов.** Сборщики приносят угол, текст пишет человек или скилл по его
  просьбе.
- **Публикует человек.** Студия и скиллы отдают текст; кнопку жмёт автор.

## Раскладка

| Папка | Что там |
|---|---|
| `voice/` | Данные автора: канон, регистры, корпус, пороги, отпечаток. `_templates/` - пустые скелеты |
| `.claude/skills/` | `write-as-author`, `corrector` (с `lint.py`, `calibrate.py`, тестами) |
| `content/` | Данные студии; формат в `content/README.md` |
| `studio/` | Next.js-интерфейс, `studio/README.md` |
| `tools/` | `trend-watch`, `voice-mine`, `platform-lab`, `threads-lab` |
| `docs/` | `method.md`, `boundaries.md`, `pitfalls.md` |
| `export/` | Скрипты, которыми этот репо собирается из приватной мастерской |

## Откуда это

Репозиторий - открытое зеркало личной мастерской одного автора. Он собирается скриптом
`export/export.py` по allowlist со стоп-листом, поэтому приватная часть (канон реального
человека, его переписка, чужие посты из замеров) сюда не попадает по построению.
Инструменты экспорта тоже здесь, чтобы вы могли держать своё так же: личное в одном репо,
открытое в другом.

Как это работает целиком, с цифрами и честными швами - дека доклада 4 сентября 2026:
