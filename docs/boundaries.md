# Границы: CLAUDE.md мастерской как жанр

Файл `CLAUDE.md` в корне личной мастерской - это не документация, а инструкция агенту,
который здесь работает. Ниже - его структура с плейсхолдерами. Самое ценное в нём -
раздел «Границы»: что легко нарушить и дорого откатить.

```markdown
# {{WORKSHOP}} - личная мастерская {{AUTHOR}}

Персональные задачи. Не продукт, не платформа: скрипты, автоматизации, разовые разборы.
Приоритет №1 - {{MAIN_GOAL}}.

Здесь нет пользователей, прода и обязательств по SLA. Зато легко случайно тронуть
чужой прод - см. границы.

## Где ты запущен

`hostname` → {{HOST}}. Здесь НЕТ: прод-БД, боевых токенов, сервисов платформы.
Опасность: прод-команды тут не падают громко, а тихо врут. Пустой `docker ps` с кодом 0
не значит «сломалось», а значит «ты не на той машине».
Всё, что требует прода, идёт через `ssh {{PROD_ALIAS}}` и только на чтение.

## Границы

1. Прод - только чтение. Личные скрипты не пишут в боевую базу, не создают миграций,
   не рестартят сервисы. Нужна запись - это задача для другого репо с его ревью.
2. Отправка сообщений из личного аккаунта - только с явного «да» в этой сессии.
   Дефолт любой автоматизации: черновик, а не отправка. Массовая рассылка - никогда.
3. Секреты не читаем и не выводим. Нужен ключ - берём из окружения по имени.
4. Личная переписка - самые чувствительные данные. Выгрузки не коммитим, не отправляем
   в сторонние сервисы. Рабочие дампы - только в `.data/` (в git не попадает).
5. Файлы соседних репозиториев из этой сессии не редактируем.

## Карта

| Файл | О чём |
|---|---|
| `docs/...` | главный документ: что уже автоматизировано, где голос, чего нельзя |
| `voice/` | данные автора |
| `BACKLOG.md` | очередь задач |
| `.data/` | дампы, не в git |

## Как здесь работают

Одна задача - одна папка верхнего уровня со своим README. Общий код - только когда
реально переиспользуется дважды. Стек по умолчанию: Python stdlib, venv внутри папки.
```

Что в этом жанре работает:

- **Границы пронумерованы и конкретны.** Не «будь осторожен», а «дефолт - черновик, а не отправка».
- **Описана машина, а не только код.** Агент, запущенный не там, должен понять это по симптомам.
- **Карта из пяти строк.** Куда смотреть в первую очередь.
- **Правило про общий код.** «Только когда переиспользуется дважды» спасает от преждевременных библиотек.
