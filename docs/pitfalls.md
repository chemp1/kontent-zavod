# Грабли, на которые уже наступили

Собрано из README инструментов за первый месяц. Каждая строка стоила вечера.

## Замеры и корпус

**Сначала проверяем, чем меряли.** Частоты канала однажды сняли разбором веб-превью
`t.me/s/<канал>`. Кнопки реакций посчитались за эмодзи в тексте, скобки-улыбки потерялись,
вопрос внутри поста прочитался как концовка-вопрос. Ошибка в четыре раза. Забанили метод
сбора, а не подкрутили правило под удобную цифру. Корпус берётся только из полного экспорта.

**Инструмент калибруется по автору, а не по идеалу.** Линтер, настроенный по корпусу,
забраковал живой короткий пост автора: в нём не было хеджа, а порог был снят по длинным
постам. Короткий пост и лонгрид устроены по-разному, поэтому пороги считаются по бакетам
длины. Если линтер ругает живой текст автора, неверен порог.

**Числа, посчитанные глазами, помечаются.** В отпечатке голоса есть доли, снятые вручную
на данных с дублями. Они помечены, а не выданы за замер. Всё, что можно пересчитать
скриптом, пересчитывается `calibrate.py`.

**Корпус с чужими постами.** Если в канале были посты, написанные не автором (SMM,
гости), калибровка честно снизит уровень проверок, которые эти посты нарушают. Для таких
случаев в seed-файле есть `"pin": true`: уровень задан руками, калибровка его не трогает.

## Площадки

**Медианы площадок отличаются в сто раз** и собраны по-разному, поэтому это порядок
величины, а не рейтинг. Лента (Дзен, TenChat) раздаёт алгоритмом, поиск (Хабр, DTF, vc)
копит охват месяцами. Регистр площадки строится на её собственном корпусе.

**Просмотры чужих постов Threads в ленте недоступны.** Виральность считается как
превышение автором своей же медианы, а не по абсолютным просмотрам.

**Тред в Threads не выигрывает у одиночного поста.** По корпусу «11 против 7» оказалось
эффектом плодовитых авторов, а внутри авторов цепочки проигрывали. Тред оправдан только
когда материал не влезает в один пост.

**Ссылка в посте - самый чистый негативный сигнал** (2% у удачных против 7% у обычных).
Ссылка должна этого стоить.

## Сборщики

**Ключевые слова матчатся по границам слова.** Подстрокой `ai` находится в «pair»,
«again» и «email»: первый прогон принёс заметку про очки для кино.

**Шортсы отсеиваются.** Сорок секунд вертикального видео не дают материала на угол,
а квоту источника забирают целиком.

**Отбор идёт по кругу, а не по дате.** Все свежие записи датированы одним днём, и
сортировка по дате отдавала все места самому плодовитому фиду.

**Разбор не сложился - url в память не кладём.** Пусть попробует завтра, а не исчезнет молча.

**Промпт подставляется не через `str.format`.** В bio автора и в выдержках из фидов
бывают фигурные скобки. Один проход `replace` по плейсхолдерам.

**Фид, который отдаёт 404, не должен быть строчкой в логе.** Треть источников однажды
молчала шесть дней подряд, и это видел только счётчик в фильтрах студии. Сборщик, который
принёс ноль, - событие.

**Порядок реплик в расшифровках.** Индекс приходит строкой, и при сортировке «10» встаёт
между «1» и «2». Сортировать числом.

**Голосовые команды боту - не источник идей.** Это диктовка ответов конкретным людям,
а не размышления вслух. Идеи живут в созвонах.

## Браузер

**Headless не пускают.** Threads и часть площадок закрыты для headless-браузера. Работает
только живой залогиненный Chrome с CLI-обёрткой на отдельной машине; хост в
`BROWSER_SSH_HOST`. Не личный аккаунт автора.

**Ровный интервал - первое, на что смотрят анти-бот эвристики.** Паузы 3–8 секунд,
один прогон в день, только чтение.

**Счётчики в карусельных карточках лежат в другой ветке DOM** и отдают ноль. Числа
берутся из хвоста текста и сверяются по лайкам. Разряды разделены неразрывным пробелом.

## Студия

**`$` в `.env` нужно экранировать.** Next раскрывает `$...` как подстановку, значение
молча становится пустым; помогает только `\$`.

**Клиентские компоненты не импортируют модули с `node:fs`.** Для них отдельные
`*-model.ts` без файловых операций.

**basePath вшивается в сборку.** Собрали без переменной - ссылки и POST уходят в корень
домена, и это не видно до первого клика. Переменная задаётся и при сборке, и при старте.

**Структура карты скилла правится руками**, из интерфейса меняется только тело файлов.
Сломанный frontmatter означает, что скилл перестаёт грузиться.

**Состояние слота календаря нигде не хранится, а выводится из идеи.** Второй статус
разъехался бы с реальностью на первой же публикации.
