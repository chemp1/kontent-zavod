# Экспорт: открытое зеркало личной мастерской

Этот репозиторий собран не руками, а скриптом из приватной мастерской автора.
Здесь лежат сами инструменты, чтобы вы могли делать так же: держать личное в
одном репо, а открытую часть - в другом, и обновлять её одной командой.

## Как это устроено

```
приватная мастерская  ──export.py──►  открытый репо
  allowlist в manifest.json             только перечисленное
  замены путей и имён                   пути открытого репо
  overlay/ (README, шаблоны, пример)    поверх источника
  стоп-лист check.py                    ничего личного
```

1. `manifest.json` - что берём и куда кладём. Запись с `"tracked": true` берёт только
   файлы, которые отслеживает git: неотслеживаемое не утечёт по определению.
2. Пути переписываются по манифесту (`src` → `dst`), затем применяется
   `replacements.json` - короткий список замен вроде «имя автора → автор».
   Правило без единого срабатывания печатается: это сигнал, что источник уже чист
   и правило можно убрать.
3. `overlay/` копируется поверх как есть: README, шаблоны, вымышленный автор.
4. `check.py` прогоняет стоп-лист по содержимому, именам файлов и бинарникам.
   Есть хоть одна находка - снапшот не пишется.
5. Снапшот синхронизируется в `dest`, сохраняя там `.git/` и `node_modules/`.

## Команды

```bash
python3 export/export.py --dry-run          # план, счётчики замен, стоп-лист; dest не трогать
python3 export/export.py                    # собрать и синхронизировать
python3 export/export.py --commit "..."     # плюс git commit в dest
python3 export/export.py --check            # только стоп-лист по существующему dest
python3 export/check.py . --staged          # что в индексе (это делает pre-commit)
```

## Настроить у себя

- `export/manifest.example.json` → `manifest.json` рядом со скриптом (в приватном репо).
- `export/stoplist.example.txt` - безличные правила (IP, UUID, id чатов, следы секретов).
  Свои имена, ники, хосты - в `stoplist.local.txt`: он в `.gitignore`.
- Хук: `git config core.hooksPath .githooks` - стоп-лист на каждый коммит.

Файлы `manifest.json`, `replacements.json` и полный `stoplist.txt` - приватные:
они описывают раскладку мастерской и содержат имена. Скрипт откажется положить их в снапшот.
