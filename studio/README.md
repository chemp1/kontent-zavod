# studio — контентная студия

Интерфейс к папке с текстами, которая ведётся по методологии «I am just a text
file»: идеи, черновики, контент-план, память об авторе и карта скилла голоса.
Студия ничего не хранит у себя — **источник правды — файлы** в `content/` и
папке скилла, **история версий — git**. Всё, что вы видите в браузере, лежит
на диске в markdown и читается так же из редактора или из сессии Claude Code.

> **Предупреждение.** Авторизации в приложении нет и не будет: оно слушает
> только `127.0.0.1` и считает, что тот, кто до него дотянулся, — хозяин папки.
> Студия **пишет файлы и делает коммиты от вашего имени** (`git config user.*`).
> Выставлять её наружу можно только за своим прокси с аутентификацией.

## Быстрый старт

```bash
# 1. Папка с текстами — новая или уже существующая
mkdir my-texts && cd my-texts && git init
git config user.name "Имя" && git config user.email "you@example.com"

# 2. Студия — подпапкой рядом с content/
git clone <этот-репозиторий> studio
cd studio && npm install

# 3. Стартовая content/ (существующие файлы не трогает)
npm run init

# 4. Поехали
npm run dev              # http://127.0.0.1:5180
```

Без `git init` студия тоже работает: файлы сохраняются, а вверху висит баннер о том,
что история версий и коммиты выключены. Без `user.name`/`user.email` коммит не
пройдёт — причина покажется рядом с кнопкой «Сохранить».

## Разделы

| Раздел | Откуда читает | Куда пишет | Кто наполняет |
|---|---|---|---|
| Библиотека, идея | `content/ideas/*/` | `idea.md` (статус), новые папки идей | вы — через форму или руками |
| Входящие | `content/ideas/` со статусом `idea` | — | то же |
| Контент-план | `content/plan/rhythm.md`, `plan/slots/` | слоты | вы; ритм правится в файле |
| Идеи из звонков | `content/plan/candidates/` | `status`, `idea` в карточке; новые идеи | внешний майнер звонков |
| Тренды | `content/trends/` | `status`, `idea` в карточке; новые идеи | внешний сборщик по `trends/sources.md` |
| Карта скилла | `content/skill-map.json` + файлы скилла | тела файлов из списка `committable` | вы; структура карты — в json |
| Память | `content/memory/` | — (предложения принимаются кнопкой, этап не реализован) | вы и подтверждённые предложения |
| Отчёты | `content/reports/*.md` + `.data.json` | — | аналитические сессии |
| Telegram, Проекты | `content/telegram/`, сводки из `.data/` | — | внешние сборщики |

Разделы без данных показывают пустое состояние с подсказкой, откуда данные
берутся; ничего пересобирать не нужно — файл лёг в папку, страница его увидела.

## Данные

Раскладка `content/` и форматы файлов описаны в [`../content/README.md`](../content/README.md)
(копия ставится `npm run init`). Ключевое:

- **`content/studio.json`** — настройки: заголовок, автор для превью
  (`name`, `handle`, `initial`) и `git.committable` — какие папки студии разрешено
  коммитить. Без файла работают дефолты («Автор», только `content/`).
- **`content/skill-map.json`** — манифест карты скилла, версия 2: узлы (файлы),
  рёбра (кто что читает), группы с подписями, папки `coveredDirs`, которые карта
  обязана описывать целиком, необязательный `upstream` для предупреждения о
  близнеце файла и раскладка — `layout` у узла, `captions`, `canvas`. Узлы без
  `layout` раскладываются сами по группам в колонки, так что стартовый манифест
  из `npm run init` рисуется без единой координаты. Без файла раздел показывает
  пустое состояние, с битым JSON — ошибку, а не 500. Манифест первой версии
  (только `nodes` и `edges`) читается как есть.
- **Отчёты** — markdown плюс `<слаг>.data.json` с `{"blocks": [...]}`: формы `kpi`,
  `bars`, `dumbbell`, `stack`, в текст ставятся маркером `[[block:N]]`.

## Переменные окружения

| Переменная | Зачем | По умолчанию |
|---|---|---|
| `STUDIO_ROOT` | папка, где лежат `content/` и файлы скилла | на уровень выше `studio/` |
| `STUDIO_BASE_PATH` | подпуть, если студия стоит за прокси не в корне домена | пусто (корень) |

`STUDIO_BASE_PATH` вшивается в сборку, поэтому задаётся и при `next build`, и при
`next start` — удобнее всего одной строкой в `.env.production`. Образец — `.env.example`.

## Устройство

| Модуль | За что отвечает |
|---|---|
| `src/lib/paths.ts` | Корень, папки данных, `resolveInside()` — единственный способ собрать путь из недоверенного сегмента |
| `src/lib/studio-config.ts` | Чтение `content/studio.json` с дефолтами и кэшем по mtime |
| `src/lib/git.ts` | История версий, `gitStatus()`, коммиты; белый список путей — из конфига |
| `src/lib/content.ts` | Чтение и запись идей; единственный модуль, знающий раскладку `ideas/` |
| `src/lib/*-model.ts` | Типы и подписи без `node:fs` — их можно импортировать в браузере |
| `src/lib/skill-map.ts` | Загрузка манифеста карты и сверка его с диском |
| `src/lib/plan.ts` | Контент-план: слоты, ритм, недельная сетка. Состояние слота выводится из идеи, а не хранится |
| `src/lib/trends.ts`, `candidates.ts` | Ленты от внешних сборщиков; студия меняет в карточке только статус |
| `src/lib/reports.ts`, `blocks.ts` | Отчёты и расстановка графиков по маркерам |
| `src/lib/frontmatter.ts` | Разбор markdown с фронтматтером, переживающий битый YAML |
| `src/instrumentation.ts` | Строка в лог при старте: корень, найден ли `studio.json`, доступен ли git |
| `scripts/init-content.mjs`, `templates/content/` | `npm run init` — стартовая `content/` |

## Границы

Заданы в коде, а не в документации:

- **Коммитятся только `content/`** и префиксы из `git.committable` в `studio.json`.
  Всё остальное недоступно, даже если путь дойдёт до `commitPaths()` по ошибке.
- **Пути проверяются**: `id` из URL проходит через `assertValidId()`, а сборка
  пути — через `resolveInside()`, который бросает при выходе за корень.
- **Исходник идеи не редактируется.** Скиллы ставят материалы автора выше
  собственного синтеза; подчищенный исходник ломает эту иерархию.
- **Студия ничего не публикует.** Хранит финальный текст и ссылку, но никуда
  не отправляет.
- **Память пополняется только с подтверждения.**

## Грабли

**`$` в `.env*` нужно экранировать.** Next грузит переменные через dotenv-expand,
и тот раскрывает `$...` как подстановку — незаэкранированное значение молча
становится пустой строкой, а кавычки не спасают, помогает только `\$`.

**Клиентские компоненты не должны импортировать модули с `node:fs`** —
сборка страницы падает. Для них есть `lib/*-model.ts`.

**`basePath` вшивается в сборку.** Собранное с `STUDIO_BASE_PATH=/studio` не
заработает в корне и наоборот: `<Link>` и `apiUrl()` уже знают префикс. Сменили
подпуть — пересоберите.

**Структура карты правится руками** в `content/skill-map.json`. Из интерфейса
меняется только тело файлов: сломанный frontmatter означает, что скилл перестаёт
грузиться.

## Что дальше

Приложение читает правду с диска и умеет её править. Агент внутри студии
(диалог вокруг идеи, мастер-версия, адаптации, вычитка) не реализован; нет
канбана и предложений в память.

Развёртывание за прокси, systemd-юниты и nginx — в [`deploy/README.md`](deploy/README.md).
