# tools/platform-lab — замер площадок: Хабр, Дзен, TenChat, DTF

Отвечает на один вопрос по каждой площадке: **что там залетает и чем залетевшее
отличается от обычного**. Продолжение замера vc.ru (карточки - в `vc/`, скрипты
того замера в репо не входят), тот же метод:
собрать корпус за год, отделить залетевшее от фона, сравнить по признакам,
результат — отчёт в студию и регистр площадки в `voice/registers/`.

Ничего никуда не публикует. Только читает.

## Что выяснилось про доступ (проверено, а не предположено)

| Площадка | Список | Метрики | Полный текст | Браузер |
|---|---|---|---|---|
| **Хабр** | `habr.com/kek/v2/articles/?hub=<алиас>&sort=rating&period=yearly` | в карточке: `readingCount`, `score`, `votesCountPlus/Minus`, `favoritesCount`, `commentsCount` | `kek/v2/articles/<id>/` → `textHtml` | не нужен |
| **Дзен** | `launcher/export?channel_name=X&country_code=ru&clid=300&lang=ru` + `channel-more` | в карточке `views`, `socialInfo`; на странице `publicationStatistics: {views, viewsTillEnd}` | тело рендерится клиентом, в HTML его нет | **нужен**, CLI `browser` по ssh |
| **TenChat** | `tenchat.ru/hashtag/<транслит>` — 20 постов по убыванию просмотров | `viewCount`, `likeCount`, `userCommentCount` в `__NUXT_DATA__` | там же, маркдауном | не нужен |
| **DTF** | `api.dtf.ru/v2.5/search?query=…&lastId=N`, фон — `timeline?sorting=date&lastSortingValue=<ts>` | `counters.total` | блоки Editor.js в том же ответе | не нужен |

Три вещи, на которые ушло время и которые больше выяснять не надо:

- **`counters.total` у Osnova — это то самое число, что показано на странице.**
  Сверено со старым браузерным замером vc: статья 2263883 — API 815, браузер 815.
  Значит проход браузером за охватами (как в старом замере vc) больше не нужен
  ни на DTF, ни на vc. Не `counters.views` — та метрика другая и меньше.
- **Дзен отдаёт просмотры в экспорте канала только при трёх параметрах разом:**
  `country_code=ru&clid=300&lang=ru`. Без `lang` приходит `views: null`.
- **Тематику на Дзене не задать разделом:** `dzen.ru/t/<тег>` — 404, `?category=`
  анонимной сессии ленту не меняет. Тематика решается выбором каналов.

## Раскладка

```
common/      fetch.py (curl + паузы + ретраи), store.py (jsonl-чекпоинты),
             normalize.py (единое представление статьи), features.py (признаки)
habr/ dzen/ tenchat/ dtf/    коллекторы по площадкам
vc/          refresh.py - досчёт охватов к корпусу старого замера vc через API
classify/    prepare.py — нарезка корпуса на батчи, INSTRUCTION.md — схема разметки
analyze.py   сводка: верх против остальных
report.py    блоки для content/reports/<слаг>.data.json
data/        карточки статей, в git
```

Полные тексты чужих статей — в `.data/tools/platform-lab/<площадка>/texts.jsonl`,
**в git не едут**: это чужой контент десятками мегабайт. В git только карточки,
на которых считается отчёт.

## Как пересобрать

```bash
cd tools/platform-lab          # запускать из папки инструмента: скрипты импортируют друг друга

# Хабр — минут десять, всё через API
python3 habr/collect.py list --pages 6
python3 habr/collect.py texts --top 100 --control 100

# DTF — минут двадцать, тоже без браузера
python3 dtf/collect.py search --pages 16          # тематические запросы = залетевшее
python3 dtf/collect.py baseline --weeks 52        # фон = обычные посты того же года

# TenChat — минут десять
python3 tenchat/collect.py --rounds 3 --top-hashtags 60   # топ по хештегам
python3 tenchat/collect.py neighbors --limit 70           # контроль: соседние посты тех же авторов

# Дзен — час, единственное место с браузером
python3 dzen/collect.py channels --calls 90       # разведка каналов
python3 dzen/seed.py                              # посев по списку кандидатов
#   → руками проставить "keep": true в data/dzen/channels.json
python3 dzen/collect.py cards --pages 16
BROWSER_SSH_HOST=<алиас> python3 dzen/fetch_text.py --limit 220   # залогиненный Chrome по ssh

# vc.ru - досчёт охватов к корпусу старого замера (файл в репо не входит)
python3 vc/refresh.py --src /path/to/articles.jsonl

# Разметка чтением и отчёты
python3 classify/prepare.py <площадка> --size 12 --cap-rest 180
#   → батчи читают субагенты по classify/INSTRUCTION.md, кладут labels/*.jsonl
python3 analyze.py --all
python3 report.py <площадка> <дата>-<слаг>
```

## Что считается «залетевшим»

Не абсолютные просмотры, а **лифт к норме своего донора охвата**: канала на Дзене,
автора в TenChat, хаба на Хабре, раздела на DTF. Причина простая: абсолютный топ
Дзена — это топ подписчиков, а не топ текста. Верхняя четверть по лифту сравнивается
с остальными, как на vc сравнивались четверти по охвату.

До сравнения отсекается: корпоративные блоги и редакция (аналог редакции на vc,
разрыв там был 45x), SEO-мусор, статьи короче 1500 знаков (900 для TenChat —
площадка короче), моложе 30 дней (не добрали охват).

## Если сломалось

- **Пустая выдача Хабра** — проверить период: `period=yearly` живой, `flow=develop` даёт
  404, у потоков свои имена (`management`, `marketing`).
- **`views: null` у Дзена** — потерялся один из трёх параметров запроса.
- **TenChat 500** — хештег передан кириллицей. Нужен `nameTransliteration`
  из поля `hashtags[]` самих постов, угадывать нельзя.
- **DTF: ноль статей после фильтра** — в поиске статья лежит в конверте `data`,
  а в ленте иногда без него; разворачивать оба варианта.
- **`Extension is not connected`** на Дзене — MV3-воркер расширения уснул, повторить.
  Браузер - залогиненный Chrome на отдельной машине с CLI `browser`, хост
  в `BROWSER_SSH_HOST`; аккаунт в нём не личный. Правила чужого браузера -
  в `tools/threads-lab/README.md`, они те же: только чтение, паузы 3–8 с, один прогон в день.
