# Разметка ниши: что статья занимает

Ты читаешь статьи с Хабра про Claude Code, вайб-кодинг и агентов в разработке.
Задача — не оценить качество, а **описать занятую делянку**: о чём статья,
на какой вопрос отвечает и чем доказывает. По этой разметке потом ищут дыру
в нише, поэтому важнее точность формулировки, чем красота.

## Правила

1. Читай статью целиком. Одна строка JSON на статью, в порядке файла.
2. `id` берётся из шапки `===== СТАТЬЯ id=... =====`.
3. `question` и `proof` пиши своими словами, коротко и конкретно —
   это главные поля, по ним будет строиться карта ниши.
4. Не выдумывай: если статья не отвечает ни на какой вопрос — так и пиши.

## Поля

| поле | значения | что значит |
|---|---|---|
| `id` | строка | из шапки |
| `subject` | `claude_code` `другой_инструмент` `сравнение_инструментов` `вайб_кодинг_практика` `агенты_архитектура` `рынок_и_профессия` `обучение` `железо_и_доступ` `прочее` | о чём статья по существу |
| `question` | строка до 90 знаков | на какой вопрос читателя она отвечает. Например: «как поставить Claude Code из России», «стоит ли бояться за работу», «как не сжечь лимиты» |
| `genre` | `гайд` `туториал` `кейс` `мнение` `исповедь` `обзор` `подборка` `новость_с_комментарием` `исследование` `перевод` | форма |
| `depth` | `поверхностно` `рабочий_уровень` `глубоко` | поверхностно — пересказ документации или новости; рабочий уровень — можно повторить по статье; глубоко — устройство изнутри, замеры, разбор отказов |
| `proof` | `свой_опыт_с_цифрами` `свой_опыт_без_цифр` `чужие_данные` `документация` `рассуждение` | чем автор подкрепляет |
| `stack` | список строк, до 5 | какие инструменты реально разбираются: `claude_code`, `cursor`, `codex`, `copilot`, `openclaw`, `qwen`, `mcp`, `skills`, `git`, `ci` и т.п. |
| `for_whom` | `новички` `практики` `тимлиды` `нетехнические` `широкая` | кому адресовано |
| `ops_side` | `да` `нет` | есть ли в статье эксплуатация: лимиты, квоты, стоимость, отказы, наблюдаемость, безопасность доступа |
| `confidence` | `high` `med` `low` | уверенность |

## Формат ответа

Пиши строки в файл, который назван в задании. Ничего вокруг JSON.

```
{"id":"1061142","subject":"claude_code","question":"как собрать проект на Claude Code с нуля","genre":"гайд","depth":"рабочий_уровень","proof":"свой_опыт_без_цифр","stack":["claude_code","mcp"],"for_whom":"новички","ops_side":"нет","confidence":"high"}
```

В ответ верни одну строку: `{"batch":"batch-03","written":10}`.
