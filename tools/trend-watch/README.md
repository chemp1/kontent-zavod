# tools/trend-watch — лента трендов для контент-плана

Раз в сутки обходит фиды фондов и новостных лент, отбирает то, о чём автору есть
что сказать, и складывает карточки в `content/trends/`. Студия показывает их
на странице `/plan/trends`.

## Что в карточке

Суть за три строки, ссылка, «почему это автору» одной фразой и 2–3 угла с площадкой.
**Постов сборщик не пишет** — решение автора 29.08.2026: угол это приглашение
подумать, готовый текст из новости — конвейер слопа. Из карточки одной кнопкой
заводится идея: тело карточки становится исходником, дальше работает `/write-as-author`.

## Как устроен прогон

1. Читает `content/trends/sources.md` — список фидов, ключевые слова, потолок
   карточек за прогон. Правка файла меняет ленту, пересобирать нечего.
2. Тянет фиды (`urllib`, stdlib): YouTube RSS каналов YC / Sequoia / a16z, RSS
   TechCrunch и The Verge, Algolia-API главной Hacker News.
3. Отбирает: свежее (3 дня), невиденное (`.data/tools/trend-watch/seen.json`), по теме.
   Каналы фондов идут без фильтра по словам — там уже человек отобрал.
4. На каждое отобранное зовёт `claude -p`. Агенту разрешён **только WebFetch**:
   он читает статью или страницу видео, но файлы пишет скрипт.
5. Пишет карточки, коммитит их и шлёт уведомление (см. `NOTIFY` ниже).

Кто автор, агент узнаёт из `voice/author.json` (`name`, `bio`); без файла
он пишет для безымянного «автора». Путь можно переопределить через `AUTHOR_FILE`.

## Настройка

Зависимостей нет: стандартная библиотека Python 3.11+ и `claude` в `PATH`.
Общий код (`common.py`: корень репо, автор, уведомления, фронтматтер) лежит
здесь же, им пользуются и соседние инструменты.

Настройки — переменные окружения, удобнее всего в `tools/trend-watch/.env`
(в git не попадает, образец — [`.env.example`](.env.example)):

| Переменная | Что |
|---|---|
| `NOTIFY` | куда слать уведомление: `stdout` (по умолчанию), `webhook`, `telegram`, `command` |
| `NOTIFY_URL` | для `webhook`: адрес, туда уходит POST JSON `{"text": ...}` |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | для `telegram`: свой бот и свой чат |
| `NOTIFY_COMMAND` | для `command`: команда через shell, текст приходит в stdin |
| `STUDIO_URL` | ссылка в конце уведомления, по умолчанию `http://127.0.0.1:5180/plan/trends` |
| `WORKSHOP_ROOT` | корень репозитория; без неё ищется ближайший `.git` над скриптом |
| `AUTHOR_FILE` | карточка автора, если она не в `voice/author.json` |

## Запуск

```bash
python3 tools/trend-watch/check.py --dry-run        # что бы взял, ничего не записывая
python3 tools/trend-watch/check.py --limit 2 --no-notify
python3 tools/trend-watch/check.py                  # обычный прогон
tail .data/tools/trend-watch.log
crontab -l                                    # 40 8 * * * /путь/к/tools/trend-watch/run.sh
```

`run.sh` — обёртка для крона: подхватывает `.env`, находит корень через `git`,
держит лок в `/tmp/<имя репо>-tools/trend-watch.lock` и пишет лог в `.data/tools/trend-watch.log`.

## Грабли, которые уже наступили

**Ключевые слова матчатся по границам слова.** Подстрокой `ai` находится
в «pair», «again» и «email» — первый прогон принёс заметку про очки для
просмотра кино.

**Шортсы отсеиваются.** Сорок секунд вертикального видео не дают материала на
угол, а квоту канала забирают целиком.

**Отбор идёт по кругу, а не по дате.** Все свежие записи датированы одним днём,
и сортировка по дате отдавала все места плодовитому TechCrunch, а Hacker News
не получал ни одного.

**Разбор не сложился — url в память не кладём.** Пусть попробует завтра, а не
исчезнет молча.

**Промпт подставляется не через `str.format`.** В bio автора и в выдержках из
фидов бывают фигурные скобки; `common.render` делает один проход и не трогает
JSON-примеры в промпте.
