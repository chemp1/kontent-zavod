# voice/ - голос автора

Здесь лежит **вымышленный автор**: Матвей Сухарев, столярная мастерская в Твери, канал «Опилки и таблицы». Он нужен, чтобы линтер, калибровка и скилл-автор запускались из коробки и было на чём посмотреть, как это работает. Замените его на себя.

Методология - «I am just a text file»: сначала личный текстовый файл автора, потом любой текст из него.

## Что здесь

| Файл | Что это |
|---|---|
| `author.json` | Имя, ник, канал, площадки |
| `i_am_just_a_text_file.md` | Канон: кто автор, во что верит, как звучит, что запрещено |
| `voice-core.md` | Выжимка канона: убеждения, сюжеты, табу, лексика |
| `channel-profile.md` | Что за канал, рубрики, что публикуется и что нет |
| `fingerprint.md` | Отпечаток голоса: структура, зачины, концовки, ритм, лексика. Раздел «Числа» заполняет калибровка |
| `examples.md` | Цитаты из корпуса с пояснением, что характерного |
| `corpus/channel.json` | Корпус постов: `[{"date", "views", "text"}]`, 28 штук |
| `corpus/samples/draft-ok.md` | Черновик в голосе автора, проходит линтер без блокеров |
| `corpus/samples/draft-slop.md` | Та же тема «нейросетью вообще», ловит 5 блокеров |
| `seed.json` | Словари автора для калибровки: хеджи, связки, служебные обороты |
| `thresholds.json` | Пороги линтера, сгенерированы калибровкой по корпусу |
| `calls.jsonl` | Одна расшифровка встречи, сырьё для скилла-автора |
| `_templates/` | Пустые скелеты всех файлов выше с подсказками |

## Как заменить автора на себя

1. Скопируйте скелеты из `_templates/` поверх файлов в этом каталоге и заполните. Начните с `i_am_just_a_text_file.md`: без него всё остальное - догадки.
2. Соберите корпус в `corpus/channel.json`: свои посты, от тридцати штук, лучше от ста. Формат - список объектов с полями `date` (ISO), `views` (число) и `text` (первая строка - заголовок, пустая, текст).
3. Впишите в `seed.json` свои словари: какими словами вы сомневаетесь, какими связками переходите от абзаца к абзацу, каких оборотов у вас не бывает. Чего нет в seed, того калибровка не увидит.
4. Прогоните калибровку из этого каталога:

```
python3 <путь к скиллу>/scripts/calibrate.py corpus/channel.json --seed seed.json --out thresholds.json --label "норма по корпусу канала автора" --report
```

Таблицу из `--report` вставьте в `fingerprint.md` после маркера `<!-- calibrate:report -->`. Предупреждения «уровень понижен» на маленьком корпусе нормальны: обязательные маркеры становятся блокерами только при 30 и больше постах в бакете (`--min-n`).

5. Проверьте, что линтер узнаёт вас:

```
python3 <путь к скиллу>/scripts/lint.py --thresholds thresholds.json corpus/samples/draft-ok.md
python3 <путь к скиллу>/scripts/lint.py --thresholds thresholds.json corpus/samples/draft-slop.md
```

Свой удачный пост должен пройти без блокеров, а текст «нейросетью вообще» на ту же тему - собрать несколько. Если наоборот, проблема в корпусе или в seed, а не в линтере.

6. Положите в `calls.jsonl` одну-две расшифровки своих встреч или голосовых: скилл-автор берёт оттуда мысли для постов.

## Правила, которые линтер проверяет механически

Длинное тире против дефиса с пробелами, буллеты, markdown в теле, эмодзи, служебные обороты, машинные конструкции («это не X. Это Y»), хеджи и связки автора, первое лицо, скобки-улыбки, ритм абзацев и предложений, длина, заголовок. Всё это - только механика. Смысловой слоп линтер не видит, для него есть канон и три вопроса в конце его вывода.
