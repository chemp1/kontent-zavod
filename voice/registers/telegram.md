# Регистр: Telegram-канал (t.me/<канал>)

Самый разговорный регистр. Для него в репо уже есть два инструмента, этот файл только маршрутизирует между ними:

- **Писать с нуля** → скилл `write-as-author` (структура поста, зачины, эталонные примеры).
- **Проверять и править готовый черновик** → скилл `corrector`: `voice/fingerprint.md` (отпечаток голоса по 562 постам канала) + `references/anti-patterns.md` (что вычищать) + `scripts/lint.py`.

Оба лежат в `.claude/skills/`. Корпус реальных постов — `voice/corpus/channel.md`.

## Правило сверки с каналом

Перед выдачей любой телеграм-текст сверяется с корпусом, а не пишется «по памяти о стиле»:

1. Прогнать черновик по `fingerprint.md`: длина, тип зачина, тип концовки, плотность хеджей и скобок-улыбок, доля строк без финальной точки.
2. Пройти чек-лист `anti-patterns.md` (длинные тире, служебные конструкции, мораль в конце и т.д.).
3. Если доступен свежий архив канала — сверить с последними 10–20 постами, а не только с отпечатком: голос дрейфует, свежие посты главнее накопленной статистики. При расхождении обновить `fingerprint.md`.

## Чем отличается от других регистров

- Скобки-улыбки, «ребят», «короче», обрывы без точки — норма.
- Никакой markdown-разметки внутри поста; жирным только заголовок.
- Концовка чаще ссылка, мысль или обрыв; вопрос к аудитории — редкость, только когда правда нужен ответ.
- Длинное тире не использовать; норма автора — дефис с пробелами.
